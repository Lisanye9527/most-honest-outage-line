# The Most Honest Outage Line

A make.fun bounty entry: the most honest status-page line an AI agent could post during an outage, written by a deterministic Python program.

Run: `python3 main.py` — writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
